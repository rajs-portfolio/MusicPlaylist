# 🎵 Music Playlist Management System

A simple **console-based Music Playlist Management System** built using **Java**. This project allows users to add, view, search, and remove songs from a playlist using an **ArrayList**.

## ✨ Features

* ➕ Add a song
* 📃 View all songs
* 🔍 Search a song by title
* ❌ Remove a song
* 🚪 Exit the program

## 🛠 Technologies Used

* Java
* ArrayList
* Scanner
* Object-Oriented Programming (OOP)

## 📂 Project File

```text
MusicPlaylist.java
```

## 🚀 How to Run

Compile the program:

```bash
javac MusicPlaylist.java
```

Run the program:

```bash
java MusicPlaylist
```
